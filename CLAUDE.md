## Project Overview

This is a Hugo-based static blog deployed to GitHub Pages. The site uses the **hugo-PaperMod** theme (not Ananke - README is outdated).

## Common Commands

```bash
# Local development with drafts
hugo server -D

# Build for production (outputs to ./public)
hugo --gc --minify

# Create a new post (draft by default)
hugo new posts/my-new-post.md
```

## Architecture

- **content/**: Blog posts in Markdown with frontmatter (see `archetypes/posts.md` for template)
- **content/posts/**: Published posts (use `hugo new` to create)
- **content/pages/**: Static pages (e.g., about.md)
- **themes/hugo-PaperMod/**: Theme submodule - do not modify directly
- **static/css/custom.css**: Custom styles that override theme defaults
- **public/**: Build output - gitignored, generated by Hugo
- **hugo.toml**: All site configuration (baseURL, title, theme, params, taxonomies)

## CI/CD

GitHub Actions (`.github/workflows/deploy.yml`) automatically builds and deploys on push to main. Hugo version in CI is 0.161.1 (local may be 0.147.7 - this is fine, just keep them close).

## Content Structure

Posts use frontmatter with: title, date, draft, description, tags, categories, toc, weight, slug. TOC is enabled by default in posts.

## Theme Configuration

PaperMod-specific params in hugo.toml control: profile mode (homepage), TOC settings, SEO, social icons, date formats. Profile mode is currently enabled on homepage.
